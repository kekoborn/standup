standup — git log, in a format your team will actually read

Your standup,
from your git log.

A tiny CLI that scans your recent commits across every repo you actually work in and spits out a markdown digest you can paste into Slack. No LLM, no SaaS, no scope creep.

$ npm install -g @kek/standup

~/code — standup
$ standup --since 24h# Standup — last 24h (you@example.com)## api- `a1b2c3d` Fix flaky retry in queue worker- `9f8e7d6` Add config flag for max retries## dashboard- `4c5d6e7` Migrate billing table to typed columns$ standup --since 1w --copy

What it actually does

Scans real repos

Point it at the local repos you work in. It reads git log and groups by repo.

Filters by you

Only commits authored by you, by name or email, over the window you ask for.

Markdown out

Stdout, file, or clipboard. Paste straight into Slack, Notion, or your standup doc.

No LLM

Deterministic. Same commits in, same digest out. No API keys, no token bill.

Install

# Requires Node.js 22+
npm install -g @kek/standup

# Create the config
cat > ~/.config/standup/config.toml <<'EOF'
name  = "Your Name"
email = "you@example.com"
repos = ["~/code/api", "~/code/dashboard"]
EOF

# Use it
standup --since 24h
standup --since 1w --copy
